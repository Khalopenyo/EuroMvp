# AGENTS.md

Эти правила обязательны для любых изменений в этом репозитории.

## Базовые принципы

- `KISS`: выбирай самое простое решение, которое закрывает задачу.
- `YAGNI`: не добавляй абстракции и расширения "на будущее" без реальной потребности.
- `DRY`: устраняй дублирование только там, где оно уже мешает поддержке.
- `SRP`: один модуль/файл — одна ответственность.
- `DIP`: зависимости передаются извне (composition root), не создаются глубоко внутри.
- `LSP`: альтернативные реализации одного слоя (например storage) сохраняют единый контракт.
- `ISP`: интерфейсы и пропсы должны быть минимальными и целевыми.

## Архитектурные границы

- `src/components/*`: только UI (разметка, события, пропсы), без бизнес-правил.
- `src/state/storefront/*`: состояние и бизнес-логика витрины.
- `src/api/*`: операции чтения/записи данных, без UI-логики.
- `src/utils/*`: маленькие чистые утилиты.

## Анти-паттерны (не допускать)

- Прямое использование `window`/`localStorage` вне `dependencies` и `utils/storage`.
- Смешивание бизнес-логики в JSX-компонентах.
- Ранняя "плагинная" архитектура и лишние слои абстракций.

## Definition of Done для каждой правки

- Сохранены границы слоёв и принципы выше.
- Нет лишних новых абстракций.
- Изменены только действительно затронутые файлы.
- Выполнена проверка сборки: `npm run build`.
