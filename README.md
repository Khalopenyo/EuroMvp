# EuroSuprise Catalog

Полноценная витрина-каталог на React + Vite для магазина сладостей EuroSuprise.

## Что реализовано

- Главная витрина с быстрыми переходами по категориям.
- Каталог с поиском, сортировкой, фильтрами, ценовым диапазоном и избранным.
- Карточки товаров и наборов с модальным окном подробностей.
- Корзина с изменением количества и удалением позиций.
- Оформление заказа с выбором самовывоза/доставки и отправкой в WhatsApp/Telegram.
- Локальное сохранение корзины, избранного и заказов через `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

Готовая сборка создаётся в папке `dist`.

## Структура

- `src/components/` - UI-компоненты (только разметка и события).
- `src/state/storefront/` - состояние и бизнес-логика витрины.
- `src/api/storefrontApi.js` - API-слой для чтения/записи данных.
- `src/constants/catalog.js` - статические данные магазина и ассортимента.
- `src/utils/` - небольшие утилиты общего назначения.
- `src/App.jsx` - композиция экранов.

## Принципы изменений

В проекте зафиксированы инженерные правила в `AGENTS.md`.

Коротко:

- `KISS` - сначала простое решение.
- `YAGNI` - не добавлять "расширяемость на будущее" без текущей задачи.
- `DRY` - убирать дубли, только когда они реально мешают.
- `SRP/DIP/LSP/ISP` - сохранять границы слоёв и единые контракты.

Перед любым merge/checkpoint:

- проверить, что не нарушены границы `components/state/api/utils`;
- убедиться, что не добавлены лишние абстракции;
- выполнить `npm run build`.
